Format attendu

PDF / Word : numéro de question, énoncé, puis propositions sur des lignes distinctes : A), B), C), D). Ligne facultative Réponse : B.

Excel : une question par ligne, colonnes Question, A, B, C, D (jusqu'à H), Réponse (ex. A ou A,C).

JSON : encodage UTF-8. type (SINGLE ou MULTIPLE) et points (1 par défaut) sont facultatifs.

{"questions": [
  {"text": "2 + 2 ?",
   "type": "SINGLE",
   "points": 1,
   "options": [
     {"text": "4", "correct": true},
     {"text": "5", "correct": false}
   ]}
]}
